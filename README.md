# eslop

> atchim's custom ebuild repository.

## Enable

Using `eselect-repository`:

```sh
eselect repository add eslop git https://github.com/atchim/eslop.git
emaint sync -r eslop
```

## Packages

- `x11-apps/sx` — start an Xorg server
- `x11-misc/srandrd` — daemon that executes commands on display output changes
